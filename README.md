# 📩 Spam Message Detection

A machine learning based web application that classifies text messages as **Spam** or **Ham (Not Spam)**.

## 🚀 Project Overview

Spam messages are unwanted messages that may contain advertisements, scams, or misleading information.

This project uses a trained machine learning model to analyze a given message and predict whether it is:

- 🟢 Ham – Normal/legitimate message
- 🔴 Spam – Unwanted or suspicious message

The application is built using **Python and Streamlit**.

## 🛠️ Technologies Used

- Python
- TensorFlow / Keras
- Natural Language Processing (NLP)
- Streamlit
- NumPy
- Pickle
